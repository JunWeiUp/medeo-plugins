# Launcher

One search box for your Mac, inspired by [Sol](https://github.com/ospfranco/sol) (MIT). Press **⌥Space** anywhere:

- **Apps** — type part of a name, its initials (`vsc` → Visual Studio Code) or its bundle id; ↩ opens it. Apps you use often rise to the top.
- **Plugins** — every command your other Medeo plugins offer, and their windows, in the same list. ↩ runs it as if you picked it in the plugin center.
- **Calculator** — `12*3`, `2^10`, `sqrt(2)`, `5!`, `(1+2)(3+4)`. ↩ copies the result.
- **Units** — `10 km to mi`, `100f in c`, `1.5gb to mb`, `3h to min`, `5 公斤 换成 斤`. ↩ copies the number.

| Keys | |
| --- | --- |
| `⌥Space` | Open or close (change it in the plugin center's shortcut settings) |
| `↑` `↓` / `⌃N` `⌃P` | Move |
| `↩` | Open, run or copy |
| `⌘1`–`⌘9` | The first nine rows |
| `Esc` | Clear the search, then close |

With an empty search the panel shows what you opened last.

## Permissions

Applications (find, show and open apps), plugin commands (list and run your other plugins' commands), its own window, clipboard write (for results) and storage (what you use most). Requires Medeo 0.1.33 or later.
