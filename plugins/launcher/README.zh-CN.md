# 启动器

一个搜索框管住整台 Mac，参考了 [Sol](https://github.com/ospfranco/sol)（MIT）。在任何地方按 **⌥Space**：

- **应用**：输入名称的一部分、首字母（`vsc` → Visual Studio Code）或 bundle id，回车打开；常用的会排在前面。
- **插件**：其他 Medeo 插件提供的所有命令和窗口都在同一个列表里，回车运行，和在插件中心点击一样。
- **计算器**：`12*3`、`2^10`、`sqrt(2)`、`5!`、`(1+2)(3+4)`，回车复制结果。
- **单位换算**：`10 km to mi`、`100f in c`、`1.5gb to mb`、`3h to min`、`5 公斤 换成 斤`，回车复制数值。

| 按键 | |
| --- | --- |
| `⌥Space` | 打开或关闭（可在插件中心的快捷键设置里修改） |
| `↑` `↓` / `⌃N` `⌃P` | 上下移动 |
| `↩` | 打开、运行或复制 |
| `⌘1`–`⌘9` | 前九行 |
| `Esc` | 先清空搜索，再关闭 |

搜索框为空时显示最近打开过的内容。

## 权限

应用（查找、显示图标并打开应用）、插件命令（列出并运行其他插件的命令）、自己的窗口、写入剪贴板（复制结果）和存储（记住常用项）。需要 Medeo 0.1.33 或更高版本。
